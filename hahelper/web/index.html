Cek streaming & data

Mencocokkan JUMLAH dan ISI setiap baris data baru (rentang menit terakhir, berhenti 5 menit lalu) antara acuan dan node cluster, setelah semua node menyusul. Yang beda dicek ulang 2 kali. Hanya membaca.

Hanya admin yang bisa menjalankan cek. Hasil cek terakhir tampil di bawah.

Perekam

Hanya admin yang bisa memulai/menghentikan rekaman. Anda bisa melihat jalannya rekaman di sini.

Cara menguji

  1. Matikan dulu skrip pengembalian bila ingin menguji tanpa itu: touch /etc/patroni/no-failback
  2. Tulis keterangan, tekan Mulai rekam.
  3. Di host Proxmox: qm stop <VMID>, atau di node: systemctl stop patroni.
  4. Tunggu pemimpin baru muncul. Nyalakan kembali node yang dimatikan.
  5. Tunggu sampai keadaan stabil (bila menguji pengembalian, ±11 menit), lalu tekan Selesai.
  6. Unduh laporan untuk dilampirkan ke PM.

Keseragaman konfigurasi antar node

Tiap node mengirim ringkasan konfigurasinya tiap 5 menit (versi, nilai penting, sidik berkas; tanpa sandi). Helper membandingkan kelimanya. BEDA = seharusnya sama tapi berbeda. SALAH = tidak sesuai aturan (mis. ufw tanpa komentar). WAJAR = memang berbeda per node (hostname, prioritas keepalived). Hanya membaca; tidak ada yang diubah di node.

Memasang pelapor di node

  1. Di server helper ini: sudo ha-helper token → salin token.
  2. Salin pasang-lapor.sh dan hahelper-lapor.py ke tiap node (5 node).
  3. Di tiap node: sudo bash pasang-lapor.sh http://<IP-helper>:8099 <token>
  4. Baris node di atas berubah jadi "baru saja" dalam beberapa detik.

Cara menjalankan

  1. Di db-node1 atau db-node2 (yang sudah terpasang pelapor, supaya hasil terkirim ke sini): salin cek-semua-tabel.sh ke /tmp.
  2. Malam hari, setelah backup 23:00: MULAI=01:00 LATAR=1 sudo bash /tmp/cek-semua-tabel.sh
  3. Kemajuan muncul di halaman ini. Ulang yang belum COCOK: TABEL_FILE=/var/log/cek-semua/<waktu>/ulang.txt sudo bash /tmp/cek-semua-tabel.sh

COCOK = jumlah & isi sama · BERUBAH = sempat beda karena sedang diubah, saat dicek ulang sama · AKTIF = terus diubah selama dicek (ulangi saat sepi / Hari-H) · BEDA = beda padahal tidak diubah (MASALAH) · UNLOGGED = tidak direplikasi · GAGAL = tidak terbaca
